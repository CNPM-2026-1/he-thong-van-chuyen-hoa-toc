# Database Design – Hệ thống vận chuyển hàng hóa hỏa tốc

## Nội dung
Thư mục này lưu trữ tài liệu thiết kế cơ sở dữ liệu của hệ thống.

## Các tài liệu
- ERD_HeThongGiaoHangHoaToc.pdf: Sơ đồ thực thể liên kết.
- TuDienDuLieu_ERD_GiaoHangHoaToc.docx: Từ điển dữ liệu.
- HeThongGiaoHangHoaToc_SQLServer.sql: Script tạo cơ sở dữ liệu SQL Server.

## Phạm vi công việc
- Xác định các thực thể và thuộc tính.
- Xác định khóa chính, khóa ngoại và mối quan hệ.
- Xây dựng từ điển dữ liệu.
- Chuyển đổi thiết kế sang câu lệnh SQL.
